The Future of Color on the Web

OKLCH is a perceptually uniform color space that enables better gradients, accessible color palettes, and access to millions of colors beyond sRGB. Perfect for Apple XDR and wide-gamut displays.

Rendering in OKLCH

Why Engineers Should Use OKLCH

OKLCH solves fundamental problems that have plagued web colors for decades.

L

Perceptual Uniformity

Equal steps in lightness values produce equal perceived brightness changes. No more fighting HSL's inconsistent brightness across hues.

P3

Wide Gamut Access

Access the full P3 color space (25% more colors than sRGB). Your Apple XDR display can show colors RGB literally cannot represent.

a11y

Predictable Contrast

Lightness directly correlates with perceived brightness, making WCAG contrast calculations intuitive and reliable.

The OKLCH Formula

/* OKLCH: Lightness, Chroma, Hue */ color: oklch(70% 0.25 145); /* L: 0-100% (perceived brightness) C: 0-0.4 (color intensity/saturation) H: 0-360 (hue angle in degrees) */ /* With alpha transparency */ color: oklch(70% 0.25 145 / 0.5);

Using OKLCH in Your Projects

CSS Custom Properties

:root { /* Define your palette in OKLCH */ --primary: oklch(65% 0.25 250); --primary-light: oklch(80% 0.15 250); --primary-dark: oklch(45% 0.2 250); /* Easy hover states - just adjust L */ --btn-hover: oklch(70% 0.25 250); }

Relative Color Syntax

/* Derive colors from a base */ --base: oklch(65% 0.2 145); /* Lighten by increasing L */ --lighter: oklch(from var(--base) calc(l + 0.2) c h); /* Desaturate by reducing C */ --muted: oklch(from var(--base) l calc(c * 0.5) h); /* Complementary color */ --complement: oklch(from var(--base) l c calc(h + 180));

Smooth Gradients

/* Always specify color space */ background: linear-gradient( in oklch to right, oklch(60% 0.25 30), oklch(70% 0.2 180) ); /* Control hue interpolation */ background: linear-gradient( in oklch longer hue, oklch(70% 0.25 0), oklch(70% 0.25 60) );

JavaScript Manipulation

// Parse and manipulate OKLCH function adjustLightness(oklch, delta) { const match = oklch.match( /oklch\((\d+)% ([\d.]+) (\d+)\)/ ); const [_, l, c, h] = match; const newL = Math.max(0, Math.min(100, +l + delta)); return `oklch(${newL}% ${c} ${h})`; }
